# Provisional - what this project started from

These documents came in with the project and were copied here unedited. They are **input to the
design interview, not the outcome of one.** Nothing here has been reviewed, agreed or signed off,
and no decision in this folder binds anything.

Where they usually come from: an idea worked out somewhere else - a conversation, a notebook, a
draft - which is a reasonable way to start a project and the reason this folder exists. Starting
from nothing is equally reasonable, and then this folder is absent.

**They are copied rather than moved, and they are never edited here.** A received document that gets
tidied stops being the thing that was received.

**When the design document is signed, do one of two things and say which.** Either fold what
survived into `docs/Design_Document.md` and delete this folder, or keep it and write one line in the
design document saying why it is worth keeping. What is not acceptable is leaving it sitting here
unread, where a later session cannot tell whether it is a decision or a discarded draft.
