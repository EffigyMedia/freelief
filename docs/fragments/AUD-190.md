### AUD-190 - In landscape on a phone, the mandala's shapes shrink below the 44 px target size, and no test checks targets in landscape

- Severity: Medium
- Area: none - omission (a layout mode added with no check against the target rule); F. User experience; H. Test coverage
- Evidence: Design section 6: 'Large targets (at least 44 by 44 CSS pixels, larger for the main actions).' The AUD-162 fix added to styles.css: '@media (orientation: landscape) and (max-height: 500px) { ... .mandala-art { max-width: min(26rem, calc(100dvh - 6rem)); } ... }'. test_mandala.py test_every_shape_in_every_design_is_a_large_target_on_a_phone runs only at 'viewport={"width": 360, "height": 740}', and test_app.py test_targets_are_at_least_44_pixels runs only at the default viewport. test_slice2.py test_a_phone_held_sideways_shows_each_play_area_whole_under_the_header checks that each area fits, but it does not check target size. Command: a Playwright script with harness.open_app measured the smallest '.mandala-part' in each of the 8 designs. At 360x740 the result was [45.0, 47.0, 45.0, 45.0, 45.0, 45.0, 45.0, 45.0]. At 844x390 it was [40.4, 42.1, 40.4, ...]. At 667x375 it was [38.3, 40.0, 38.3, ...]. At 740x360 it was [36.2, 37.8, 36.2, ...]. (quoted in round UNT-155) (quoted in round UNT-155)
- Impact: A person with shaky hands who turns the phone sideways gets mandala shapes up to 18% under the size that the design and the owner's 44 px ruling (RLG-047) require, and the shapes are harder to hit. Every automated check stays green, because no test runs in landscape. The RLG-033 landscape check asks 'does each exercise fit', not whether it can still be tapped.
- Direction: In the landscape rule, keep the mandala art at the size where every part is at least 44 px (about 328 px), and let the page scroll or put the swatches beside the art. Run the mandala target test, and test_targets_are_at_least_44_pixels, at 667x375 and 844x390 as well as in portrait. Add 'tap targets when sideways' to the RLG-033 landscape check.
- Effort: S
- Found by: the omission lens of round [[UNT-155]].
