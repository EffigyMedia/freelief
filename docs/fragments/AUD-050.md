### AUD-050 - Forced-colors (high contrast) mode is not handled, so the colour-sort tiles can look the same

- Severity: Low
- Area: none - omission (unhandled mode)
- Evidence: Quoted in round UNT-010. styles.css has "@media (prefers-color-scheme: light)" and "@media (prefers-reduced-motion: reduce)", and has no forced-colors rule. sort.js sets the shade only as "tile.style.backgroundColor = `hsl(...)`", and the tiles have no visible text. Confidence: from how forced-colors mode replaces backgrounds. Not tested. (quoted in round UNT-010)
- Impact: A sighted user in Windows High Contrast mode can see five identical buttons, so the activity is impossible for them. This goes against 'works for everyone'.
- Direction: Add forced-color-adjust: none to .sort-tile (or a visible shade label in forced-colors mode), and check the breath guide and the bubbles under forced colors.
- Effort: S
- Found by: the omission lens of round [[UNT-010]].
- **RULED 2026-10-08T13:13:49-04:00** — Fixed in UNT-077: in forced-colors mode the sort tiles, mandala shapes and swatches keep their colors (forced-color-adjust none) with system-color outlines. Test: under forced colors the five tiles keep five colors; it fails without the rule.
