**What was checked and found right:** I checked these items and they are correct (quoted in this round).

Start-up failure paths: boot() loads config, strings and crisis lines together. A failure puts the static fallback back: 'if (staticFallback && !staticFallback.isConnected) document.body.replaceChildren(staticFallback)'. fallback.js shows the fallback if 'dataset.ready !== "true"' after REVEAL_AFTER_MS = 2000, and it depends on no module. test_startup.py covers a failed config.json, strings/en.json, app.js and screens/menu.js, JavaScript off, a screen start that fails, and a menu that cannot start. A failed crisis file is not fatal: crisis.js sets 'data = null' and logs 'Freelief could not load the crisis lines'. The help dialog then takes its directory link from config.crisis.directoryUrl.

Router: show() falls back to the menu on a failed import or a failed start(), and the address is corrected with 'history.replaceState(history.state, "", `#${DEFAULT_ROUTE}`)'. The 'request !== showing' counter drops a stale screen.

Service worker: it deletes only its own caches ('key.startsWith(PREFIX) && key !== CACHE') and answers only from this version's cache. A Cache Storage fault falls back to the network ('.catch(() => fetch(event.request))', AUD-059). The precache bypasses the HTTP cache ('cache: "reload"'). The AUD-120 guard stores a network file only when 'thisVersionIsDeployed()' is true. The repair reply is heard and logged ('Freelief could not repair its offline copy.'). The second-window rule replies '{ skip: false }' when another window is open, and test_a_second_window_does_not_take_the_version_from_a_window_in_use covers it.

Storage: every localStorage access in settings.js is in try/catch. Corrupt JSON reads as '{}'. A stored value that this version cannot read is kept in 'foreign' and written back, so a rollback loses no choice (AUD-121).

Resource growth: bubbles, calm and ripple each use a 'later()' that 'drops its own id when it fires'. Each stop() clears its timers and cancelAnimationFrame. calm.stop() releases the wake lock, removes the 'fullscreenchange' listener and exits full screen. breathe resets 'run.timers = []' on each phase. wakelock.js releases a lock that arrives after it is no longer wanted (AUD-081). The Visualizer removes old pattern layers after the cross-fade.
