### AUD-041 - Design Stage 8 disagrees with the code on the ctx contract, the tunables, the routes and inline CSS

- Severity: Low
- Area: G. Documentation quality
- Evidence: Quoted in round UNT-010. Stage 8: "`ctx` gives `strings`, `settings` (read-only), `config`, `motion` and `audio`." app.js passes `{ t, list, config, motion, audio, rhythm: getSetting("rhythm") }`. Stage 8 tunables: "the international directory URL" is said to be in config.json, but the directory URL is in data/crisis-lines.json. The routing paragraph lists "(`#breathe`, `#menu`, `#ground`, `#statements`, `#settings`)", but ROUTES also has bubbles, trace, sort, about, standards and feedback. Stage 8 says "Inline the critical CSS", but the CSP is `style-src 'self'` and index.html links styles.css. (quoted in round UNT-010)
- Impact: The design is the live authority, and four statements in its architecture stage are false. The next implementer may follow the wrong contract.
- Direction: Rewrite those Stage 8 sentences to match the code, deleting the old wording. For the inline-CSS reversal, add a dated Decision Log entry.
