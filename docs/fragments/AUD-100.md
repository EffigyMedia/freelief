### AUD-100 - Adding a screen needs four lists, but AGENTS.md names two

- Severity: Low
- Area: B. Code quality and maintainability
- Evidence: Quoted in round UNT-082 at 82a1c6d. AGENTS.md Architecture: "a new screen is added to `ROUTES` in `app.js` and to `FILES` in `sw.js`." The code also has the menu's `const ITEMS = [ { route: "breathe", ... }, ... ]` in screens/menu.js and `const QUIET_FOOTER = new Set(["breathe", "bubbles", "trace", "sort", "ripple", "mandala", "calm"])` in app.js. A new activity that is missing from ITEMS cannot be reached from the menu. One missing from QUIET_FOOTER shows the full footer, against the UNT-062 decision. test_offline.py enforces only FILES. (quoted in round UNT-082)
- Impact: The next activity added by following AGENTS.md could ship unreachable or with the wrong footer, and only some tests would catch it.
- Direction: Name all four lists in AGENTS.md, or derive ITEMS and QUIET_FOOTER from one list of activities in app.js or config.json. Add a test that every activity route is in the menu and in the quiet-footer set.
- Effort: S
