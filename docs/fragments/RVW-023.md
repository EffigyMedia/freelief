**Closing:** One new Medium finding stops me from saying "Sound as written". The service worker takes a cache name from the ?v= query with no check, for navigations too, and its activation never deletes the highest-named freelief- cache. A cache that a sibling site plants on the shared origin therefore survives every Freelief update, and a link can show it under Freelief's address. This voids the limit on which design section 9 accepts the shared-origin risk. I confirmed it in a scratch probe: ?v=999.0.0 served the planted page.
