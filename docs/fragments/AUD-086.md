### AUD-086 - setup reports complete but leaves WebKit uninstalled, which doctor and test_engines.py require, so a cold clone fails doctor right after setup

- Severity: Low
- Area: H. Build & deployment readiness
- Evidence: tools/freelief.py cmd_setup (quoted in round UNT-082) runs only `uv venv` and `uv pip install --python .venv playwright==1.63.0 axe-playwright-python==0.1.8`, then prints '[ OK ] setup complete'. cmd_doctor: `for name, required in (("webkit", True), ("firefox", False)):` fails with 'run: .venv python -m playwright install webkit'. test_engines.py calls `engine("webkit")`. tools.toml declares `required = []`. AGENTS.md: '`setup` — create `.venv` and install Playwright and axe.' (quoted in round UNT-082)
- Impact: On a cold clone (a volunteer, a fresh machine, a later CI), setup says OK, but doctor then prints NOT READY and the WebKit test fails. The fix is printed, so nothing is silent, but the one command meant to make the line ready does not do it, and the session must find the manual step in doctor's output.
- Direction: Have setup run `.venv python -m playwright install webkit` after the pip install, because the pinned Playwright needs its own matching WebKit build. Update the AGENTS.md setup line to match. Or declare the step where setup reports it.
- Effort: S
