A rollback by moving `live` to an older commit changes version.js, which the worker imports, so installed users are moved back too.

**Findings: 5.**
- Medium: 'Update now' deletes the offline copy and the worker before it knows the network works, so on a dead connection the app is gone until the device is online again
- Medium: After a touch, a mid-session update serves the new version's lazy screens to the old shell, and a screen that cannot load bounces to the menu and leaves its own link dead
- Low: bench enforces only the hard targets, not the recorded tolerance, and launch and size are each 34% over baseline with no log entry since v0.5.10
- Low: The worker's fetch handler has no catch, so a Cache Storage error answers every request with a network error, even online
- Low: The worker reports whether the cache repair worked, but nothing listens, so a failed repair is invisible
