### AUD-151 - The Kaleidoscope opens urgent help by finding the shell's button by class name, not through ctx

- Severity: Low
- Area: B. Architecture quality
- Evidence: Quoted in this round. activities/calm.js: "container.querySelector(\".calm-help\").addEventListener(\"click\", () => { leaveFull(); document.querySelector(\".help-open\").click(); });". Design section 8: the shell owns "the 'Need urgent help?' control". Contracts: "`ctx` gives the text functions `t` and `list`, `config`, `motion`, `audio`, `haptic`, `keepAwake`, and the read-only setting values". ctx has no way to open help. test_safety.py covers the path (.calm-help), so a break today is caught. (quoted in round UNT-124)
- Impact: The only route to help from full screen depends on a CSS class in another module's markup. A rename of .help-open in app.js breaks a safety path. Only a test outside the module notices it, and no contract says that the class is public.
- Direction: Add an openHelp() function to ctx in app.js, and call ctx.openHelp() from calm.js. Then the shell owns how help opens, and the contract names it.
- Effort: S
- Found by: the whole-design lens of round [[UNT-124]].
