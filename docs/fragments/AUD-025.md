### AUD-025 - The claim 'sends nothing after install' omits the browser's update check to GitHub on each online launch

- Severity: Medium
- Area: none - omission (unstated network behaviour)
- Evidence: Quoted in round UNT-010. strings/en.json about.privacy1: "it sends nothing over the internet after it is installed." REQ-015: "sends nothing over the network after install." The design and the technical reference never mention the service-worker update check. sw.js imports "version.js", and with default registration the browser revalidates sw.js and its imports against effigymedia.github.io when an online person opens the app. test_no_request_leaves_the_origin filters requests by "urlparse(url).netloc not in (origin, \"\")", so a same-origin request does not count. That test checks 'no other origin'. It does not check 'nothing sent'. Confidence: from reading the code and service-worker update behaviour. The request was not captured in this round. (quoted in round UNT-010)
- Impact: The privacy statement and the requirement promise more than the app does. GitHub can see the IP address and time of each online launch of a panic app. Principle 4 says true claims only. A careful reader or a regulator could call the claim false.
- Direction: Decide the wording with the owner. For example: "The only thing that reaches the internet is your browser's check for a newer Freelief, from GitHub Pages. It carries nothing about you." Change about.privacy1, the README and REQ-015 (with history) to match, and document the update check in the app-shell technical reference.
