### AUD-076 - The pin test does not cover the directory link in data/crisis-lines.json, the only curated route for anyone outside the five pinned countries

- Severity: Medium
- Area: E. Security
- Evidence: Quoted in this round at 82a1c6d (unchanged at b7964ce). The design's Section 9 states the control against a tampered crisis line: "a repository test pins each crisis number to its record, so a changed number fails the tests unless its record changes too (`test_every_crisis_number_is_pinned`)". test_repo.py builds what it compares only from `data["regions"]`: `found = {code: {...} for code, region in data["regions"].items()}` and `assert found == CRISIS_PINS`. Nothing compares `data["directory"]`, which holds `"url": "https://findahelpline.com/"`. app.js uses that value for the directory button whenever the crisis file loads: `const directoryUrl = directory ? directory.url : config.crisis.directoryUrl;`. The other two copies are pinned: test_startup.py asserts the config.json fallback (`get_attribute("href") == "https://findahelpline.com/"`, only when the crisis file fails to load), and test_repo's URL_ALLOWED pins the copy in index.html. test_app.py only counts the link (`page.locator(".directory a").count() == 1`). Also, crisis.js deliberately returns no region for a device with no region set (AUD-026), and only US, CA, GB, IE and AU are curated. For everyone else the dialog shows `help.emergencyUnknown` and this directory link as the only curated route. (quoted in round UNT-082)
- Impact: A mistyped or tampered directory URL in data/crisis-lines.json passes every test and the release build. After the next version, every person outside the five curated countries, and every person whose device sets no region, gets a dead link or a hostile page as their one crisis route. This is the threat the design names ("a tampered crisis line"), and it lands on the largest group of users.
- Direction: Extend the pin to the directory: assert `data["directory"]["url"]` (and its name) against a pinned value in test_every_crisis_number_is_pinned, or add a test that the dialog's directory href equals the pinned URL when the crisis file loads. In the design's Section 9 sentence, say that the pin covers the directory as well as each number.
