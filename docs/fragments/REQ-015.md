### REQ-015 — Freelief collects no personal data and sends nothing about the person. After install, the only network requests are the browser's check for a newer version of Freelief and the download of Freelief's own files to update or repair its offline copy, all from GitHub Pages, and they carry nothing about the person. Only the person's settings are stored, and only on the device.

**History.**
- 2026-10-07 (agreed in the design interview): "Freelief collects no personal data and sends
  nothing over the network after install."
- 2026-10-08 (owner, AUD-025): changed. When an online person opens the app, the browser asks
  GitHub Pages for `sw.js` and `version.js` to check for a new version. GitHub can see the address
  and the time of that request. The requirement now states it, and the About text says: "Freelief
  sends nothing about you. The only thing that reaches the internet is your browser's check for a
  newer version of Freelief, from GitHub Pages."
- 2026-10-09 (owner, AUD-098; UNT-101): was "...the only network request is the browser's check for a newer version of Freelief...". The app also downloads its own missing files to repair its offline copy. The owner chose to name both.
