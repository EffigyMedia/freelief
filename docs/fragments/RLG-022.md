### RLG-022 — Portrait only
- **RULED 2026-10-08T00:16:00-04:00** — Built in UNT-045 as v0.5.31. manifest.webmanifest sets orientation portrait, which applies to the installed app on a phone. A browser tab cannot be locked (the Screen Orientation API locks only in full screen) and a desktop ignores it, so the app still works in any shape there; a rotate-your-phone screen was rejected because it would block help. The manifest test checks the key. 106 tests. The owner checks it on a phone with the app installed (it may need a reinstall to take effect).
