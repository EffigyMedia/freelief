### AUD-140 - exercises_and_settings.md describes a soundChanged contract, a settings boot and a sound table that the code no longer has

- Severity: Medium
- Area: G. Documentation quality
- Evidence: Quoted in this round. docs/technical_references/exercises_and_settings.md says: "A screen may also export `soundChanged(on)`. The shell calls it when the sound button changes. Only the Visualizer uses it." git grep soundChanged finds it only in this file and in RLG-026, and app.js calls no such hook. The file says: "It keeps a stored value only if it passes its check, so a value that is no longer a setting (`calmMode` and `natureSound`, removed in v0.8.2) is dropped." settings.js (AUD-121, v0.8.12) does this instead: "else foreign[name] = value;", and save() writes "{ ...foreign, ...chosen }". The file says: "`resetSettings()`, behind Reset settings, removes every stored value". settings.js has "const KEPT_BY_RESET = [\"sounds\"];". The sound table lists "| `glass(note)` | Trace |" and "| `play(name)` | Trace, Unblock |". audio.js exports no glass(). It exports sand(), which the table omits, and garden.js calls audio.play("choose"). The Vibration section lists the pattern "`loop`" and "the trace tone". The omission lens found the `glass(note)` | Trace row as part of a wider sweep of removed screens. (quoted in round UNT-124)
- Impact: This is the owning reference for exercises, Settings and audio. A session that trusts it builds a soundChanged hook that nothing calls. It also expects retired settings to be dropped when they are kept, and it misses Zen Garden's sound. The next defect in Settings or audio is then debugged against a wrong description.
- Direction: Sync the file with the code in one unit: remove the soundChanged paragraph; describe the AUD-121 rule for stored values that this version cannot read; say that a reset keeps `sounds`; replace the glass and Trace rows with `sand()` for Zen Garden and add Zen Garden to `play`; remove `loop` and the trace tone from the Vibration section. Name each replaced sentence in the unit's close.
