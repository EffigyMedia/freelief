### AUD-073 - The live preview was moved about nine times after v0.5.2 with no record of the owner's yes or of which version is live

- Severity: Low
- Area: none - omission (record of a deploy)
- Evidence: Quoted in round UNT-051. AGENTS.md: "Before 1.0, `live` is a public *preview*: move it only with the owner's yes for that move". `git reflog show origin/live` lists 10 pushes. The latest is f90a4ce (v0.5.34), and the earlier ones include 941a719, 8032424, fd08c0d, 16e601d and baf3df0. A grep of the UNT fragments and the changelog for a live move finds only UNT-014 ("The live preview now serves v0.5.2 ... by the owner's yes"). Neither the thread nor the changelog says which version the preview serves. (quoted in round UNT-051)
- Impact: Nobody can show afterwards that each public deploy had the owner's yes, which is the control that replaced the gate before 1.0 (AUD-003). An auditor or a bug reporter cannot tell which version real users have. This round had to find it with git.
- Direction: Record each move of live with the owner's yes, for example as a line in the changelog entry of that version or as a short unit like UNT-014. Name the version that live serves in the thread or the README. If the yes is given in chat, quote it in the record.
- Effort: S
- Found by: the omission lens of round [[UNT-051]].
