### AUD-044 - The urgent-help dialog can be closed by touch only from its bottom, after all the content

- Severity: Low
- Area: F. User experience
- Evidence: Quoted in round UNT-010. app.js: `body.push(details, close);`, so Close is the last element. styles.css: `.close { margin-top: 1rem; width: 100%; }`, which is not sticky. On a 360x640 screen the dialog content runs past the fold before Close is reached. A native dialog does not close on a backdrop tap. (quoted in round UNT-010)
- Impact: A touch user who opened help by mistake, or is done with it, must scroll the whole list to return to breathing. Escape works only with a keyboard.
- Direction: Add a close control at the top of the dialog, or make Close sticky. The owner checks the result on a phone.
- Effort: S
- Found by: the whole-design lens of round [[UNT-010]].
