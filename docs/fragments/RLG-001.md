### RLG-001 — Slice 1 - walking skeleton: breathing guide at launch, Need urgent help crisis lines, self-help line, installable and offline, keyboard and screen-reader path
- **RULED 2026-10-07T13:16:00-04:00** — The walking skeleton (design document, Stage 10). It proves the riskiest assumption: a plain progressive web app on GitHub Pages can install, work offline, show the breathing guide within 1 second, and be fully usable by keyboard and screen reader. It holds the shell, the breathing guide with the default rhythm, the Need urgent help control with the first curated crisis lines (US, UK, Canada, Australia, Ireland) and the international directory, the self-help line, the manifest, the service worker, config.json, strings/en.json, the browser tests and bench. It is done when the offline, accessibility, smoke and crisis tests pass, bench meets the 1-second and 150 KB targets, and the owner has checked it on a phone. Then the owner is asked about the public repository.
- **RULED 2026-10-07T13:25:28-04:00** — Built in UNT-004 as v0.1.0. All 19 tests pass, including offline after one visit, axe WCAG 2.2 A and AA plus AAA contrast in both themes, keyboard paths, reduced motion, 44-pixel targets, region selection and the complete offline cache list. bench meets REQ-026 (110 ms), REQ-027 (10 ms) and REQ-028 (41 KB). Every crisis line was checked against its official source on 2026-10-07. Still open from the done-when: the owner's check on a real phone, which needs the app served over HTTPS, so it waits on the owner's yes to create the public repository.
