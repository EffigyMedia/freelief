### AUD-020 - REQ-030 (must) requires the email route, but the design allows a release with the email button hidden

- Severity: Medium
- Area: A. Requirement compliance
- Evidence: Quoted in round UNT-010. REQ-030, priority must: "A feedback page opens a pre-filled GitHub issue ... and, as a second choice, a pre-filled email to the public project address." Design Stage 11 open question: "The owner decides, before the first release that shows the email button. Until then the button is hidden."
