### AUD-182 - The documented rollback and deploy commands push a tag to the live branch, but every preview- tag is annotated, and git refuses to write a tag object to a branch

- Severity: Medium
- Area: H. Build & deployment readiness (rollback)
- Evidence: Round UNT-155. AGENTS.md Incident row: 'The owner may move `live` back to the previous tag at once ... `git push --force origin <tag>:live`.' Release step 5: '`git push origin vX.Y.Z:live`'. Design Decision Log (AUD-105): '`git push --force origin vPREVIOUS:live`'. The command `git for-each-ref --format='%(refname:short) %(objecttype)' refs/tags` gave '15 tag', so every tag is annotated; `git cat-file -t preview-0.8.22` printed 'tag'. A scratchpad probe made a repository with an annotated tag preview-0.0.1 and a local bare remote. `git push --force origin preview-0.0.1:live` printed "remote: error: cannot update ref 'refs/heads/live': trying to write non-commit object ... to branch 'refs/heads/live'" and "! [remote rejected] preview-0.0.1 -> live (invalid new value provided)", exit 1. `git push --force origin "preview-0.0.1^{}:live"` printed '(forced update)', exit 0. This is what remains of the fixes recorded for AUD-121 and AUD-178. (quoted in round UNT-155)
- Impact: The Incident path is for a wrong crisis number or a broken start-up in live. An owner who follows the row exactly gets a rejected push and a cryptic error, and the defective version stays live while they work out why. The Release deploy step fails the same way if the v tags are made annotated like the preview tags. That failure is loud and deploys nothing, but it blocks a release at its last step. No rollback has ever been run, so nothing has shown this.
- Direction: Peel the tag in every documented command: `git push --force origin <tag>^{}:live` in the Incident row, design section 9 and the AUD-105 and AUD-121 Decision Log entries, and `git push origin vX.Y.Z^{}:live` in Release step 5. Or state that release and preview tags are lightweight. Rehearse the rollback once against a scratch remote, record the result, and add an Instruction Changelog entry. Add a test_repo case that runs the documented command against a local bare repository.
- Effort: S
- Found by: the operations lens of round [[UNT-155]].
