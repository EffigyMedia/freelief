**What was checked and found right:** Checked in this round at e695bfb, and found right:
- CSP: index.html has `default-src 'self'; img-src 'self' data:; style-src 'self'; script-src 'self'; connect-src 'self'; worker-src 'self'; manifest-src 'self'; base-uri 'self'; form-action 'none'`, and test_repo.py `test_the_content_security_policy_is_exactly_the_reviewed_one` pins that exact string. With no 'unsafe-inline', a `javascript:` URL that an unescaped data value might carry cannot run.
- No other origin: `test_nothing_loads_from_another_origin` and `test_shipped_code_names_no_other_address` hold. sw.js fetch returns early with `if (event.request.method !== "GET" || url.origin !== self.location.origin) return;`. Every `fetch(` in shipped code takes a relative path (config.json, strings/en.json, data/*.json). A `git grep` over shipped .js for localStorage, sessionStorage, indexedDB, document.cookie, geolocation, sendBeacon, XMLHttpRequest, WebSocket and EventSource found only settings.js, which is the one storage owner the design names.
- Trust boundaries in the app: (1) The URL hash: `return Object.hasOwn(ROUTES, name) ? name : DEFAULT_ROUTE;`. (2) Stored settings: validators() accepts only own keys and checked values (`Object.hasOwn(config.breathing.rhythms, v)`, `typeof v === "boolean"`, `helpRegion: (v) => v === "auto" || /^[A-Z]{2}$/.test(v)`). (3) The device region goes through `new Intl.Locale(tag).region` in try/catch. (4) linesFor uses `Object.hasOwn(regions, regionCode)`. (5) Phone links strip everything but digits and plus: `const dial = (number) => number.replace(/[^\d+]/g, "")`. The urgent-help dialog is built with element()/textContent and not with innerHTML.
- Tampered crisis line: `test_every_crisis_number_is_pinned` compares emergency, call, text and web for every region, and also `data["directory"]["url"] == DIRECTORY_PIN`. Every `web` link and every research source URL is https. Design section 9 states this as the real control, together with the shared-origin trust dependency (AUD-004, AUD-007, owner-accepted). `gh api .../rulesets` returned `[]` and `live` is "Branch not protected", which agrees with the design's statement "No enforced review of a commit exists".
- Feedback privacy: the GitHub link carries only `template` and `title` (`issue.searchParams.set("template", ...)`, `issue.searchParams.set("title", title)`) and never the person's words (AUD-055). The issue template says "GitHub issues are public. Please do not include health or personal details." `feedbackEmail` is "" in config.json, so the mailto route is hidden.
- Secrets and the never-commit list: .gitignore holds `.venv/`, `output/`, `input/excluded/`, `.claude/settings.local.json`, `.env`, `*.key`, `*.pem` and `feedback/`. `git log --all -p` grepped for ghp_, github_pat_, gho_, AKIA, PRIVATE KEY, xox, sk- and AIza found only the earlier reviews' own descriptions of the same scan. `git grep` for local user paths found none in shipped files. The remote `https://github.com/EffigyMedia/freelief.git` holds no credential. input/committed holds only .gitkeep and input/excluded is empty. docs/inbox/.gitignore keeps messages out (`*`, `!LEDGER.md`). .claude/settings.json holds only `enabledMcpjsonServers`.
