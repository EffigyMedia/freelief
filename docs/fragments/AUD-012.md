### AUD-012 - The browser that the tests, bench and icon tool need is not installed by setup, not checked by doctor and not declared

- Severity: Medium
- Area: H. Dependency management
- Evidence: Quoted this round (UNT-010). harness.py: `_browser = _playwright.chromium.launch(channel="chrome")` with fallback `_playwright.chromium.launch()`. cmd_setup only runs `uv venv` and `uv pip install ... playwright axe-playwright-python`; it never runs `playwright install`. cmd_doctor checks `import playwright, axe_playwright_python` but never launches a browser. tools.toml: `required = []`, `optional = []`. Health check: `ls $LOCALAPPDATA/ms-playwright` -> 'No such file or directory', so the fallback browser is absent and all 48 tests pass only because Google Chrome is installed system-wide. make_icons.py uses `channel="chrome"` with no fallback. AGENTS.md: "Playwright uses the Chrome already on the machine." (quoted in round UNT-010)
- Impact: On a cold clone on a machine without Chrome (a volunteer, a fresh machine, a later CI), `setup` succeeds and `doctor` prints READY, then every browser test and `bench` fails at launch. Audit_and_Testing.md section 5 calls a suite that only passes under a special condition a finding.
- Direction: Either have `setup` run `.venv python -m playwright install chromium` so the fallback exists, or make `doctor` launch the browser once and fail with 'install Google Chrome or run setup'. Declare the browser in tools.toml (add a catalog entry for Chrome if the registry needs one). Make make_icons.py use harness.browser() for the same fallback.
- Effort: S
- Found by: the operations lens of round [[UNT-010]].
