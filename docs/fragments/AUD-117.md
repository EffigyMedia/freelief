### AUD-117 - A bad edit deleted the shared helpers' storage rule from AGENTS.md and left a duplicated half-line, with no Instruction Changelog entry

- Severity: Medium
- Area: G. Documentation quality
- Evidence: Quoted in round UNT-104. AGENTS.md Architecture: "`wakelock.js` (keeps the screen on during breathing and the Visualizer; fails\n  silently), `motion.js` (reduced-motion detection, which every animation asks). They **must not**\n  silently), `motion.js` (reduced-motion detection, which every animation asks)." `git log -L` shows e4f2f93 (v0.7.6, UNT-094) replaced "They **must not** touch storage except by reading `settings.js`." with the duplicated line, and added the background.js bullet. Design section 8 states no storage rule for audio.js, haptics.js, wakelock.js or motion.js, so the rule now has no written home. Instruction_Changelog.md has no entry for this AGENTS.md change. Its rule: "when an instruction changes, add an entry here **and** update the operative doc". The code still complies: these helpers only `import { getSetting } from "./settings.js"`, which the lost rule allowed in so many words. Separately, the Release row names `python tools/freelief.py files` and the Commands list does not. (quoted in round UNT-104)
- Impact: AGENTS.md is the first file that every session reads. The architecture boundary for the four shared helpers is gone, and the sentence that held it now ends mid-sentence, with no object. A later session that adds storage to a helper, or a new helper, breaks no written rule. The settings.js line still guards localStorage, so the reach is limited. This is the AUD-096 class again: an AGENTS.md change with no log entry.
- Direction: Restore "They **must not** touch storage except by reading `settings.js`." and remove the duplicated half-line in the same edit. Add the storage rule for the helpers to design section 8's Must-not column so that it has a design home. Add a dated Instruction Changelog entry for the background.js addition and the repair. Also name `python tools/freelief.py files` in the Commands list. Add a test_repo check for a sentence that ends in "must not".
