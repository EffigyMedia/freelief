### RVW-010 - the operations lens of round [[UNT-082]]

**Re-checks of the previous round:**
- [[AUD-057]] partly done: AUD-057 is marked built, but its fix holds only when one page is open. app.js: `const offerTakeover = (worker) => { if (worker && hadController && !interacted) worker.postMessage("skip"); };`. Here `interacted` is the flag of the page that sends the message, and no other page is consulted. sw.js: `if (event.data === "skip") { self.skipWaiting(); return; }` and activate does `.then(() => self.clients.claim())`. Scratch probe in round UNT-082 (a copy of the app served by harness.serve): page A installs the app and is touched, version.js goes to 9.9.7 and mandala.js is broken in the same way as the AUD-057 test, the update waits, and then page B opens fresh. Result: 'A version still 0.6.16', 'caches: ['freelief-9.9.7']', and after `location.hash = 'mandala'` page A shows 'A shown: menu hash: #menu parts: 0'. The old cache is deleted under a touched page, and that page then loads the new version's lazy screen. The hash fix in show() works: the address became #menu. The test test_after_a_touch_a_new_version_waits_and_the_session_keeps_its_own_files closes page A before the 'next open' page, so it never covers a second window. Direction (a) of the finding said: 'do not call skipWaiting/clients.claim while a client is open after interaction'. Not met when a second window, such as the installed app plus a browser tab, opens.

**What was checked and found right:** Audited state: HEAD b7964ce (v0.6.16). Its diff from 82a1c6d touches styles.css, two tests, version.js and records, and none of the logic quoted below. The only open AUD- finding is AUD-072 (area G, store index). It belongs to the whole-design lens, so this review does not re-check it.

Checked and right (quoted in round UNT-082):
- Install is atomic. `cache.addAll(FILES.map((file) => new Request(file, { cache: "reload" })))` runs inside install's waitUntil, so a failed file fails the whole install and the old version stays (AUD-013).
- Activate deletes only Freelief's own caches: `.filter((key) => key.startsWith(PREFIX) && key !== CACHE)` (AUD-014). The fetch handler answers only from this version's cache, and a Cache Storage fault falls back to the network: `.catch(() => fetch(event.request)), // a Cache Storage fault falls back to the network (AUD-059)`.
- Repair failure is heard. app.js logs `console.warn("Freelief could not repair its offline copy.")` when the reply is `heal === false` (AUD-060).
- 'Update now' removes nothing before the network works. It runs `await registration.update()` before any cache deletion, and on failure it shows `settings.updateFailed` = 'Could not update. This version still works offline.' (AUD-056).
- Start-up fails soft. `boot().catch(...)` restores `staticFallback`. fallback.js reveals it after 2000 ms and does not depend on config.json. A screen that fails to load or start goes to the menu and `history.replaceState(history.state, "", `#${DEFAULT_ROUTE}`)` (AUD-002, AUD-008). test_startup.py covers config.json, strings, app.js and menu.js aborts, JavaScript off, and a failed screen start.
- settings.js wraps every storage access in try/catch, and `read()` returns `{}` on a parse error. Inherited names are refused with `Object.hasOwn`. A blocked write keeps the choice 'for this visit only'.
- breathe.js resets `run.timers = []` at each phase, and bubbles.js `later()` drops each id when it fires. The AUD-038 fix holds where it was applied.
- doctor launches the test browser and WebKit. It fails on a missing JSON file: `check(False, f"{name} exists", "the app needs it")`. It checks that sw.js imports version.js and that every cached file exists, and that every test file compiles. It reports the Firefox gap as WARN, which RLG-033 tracks ('install the Microsoft Visual C++ runtime ... Then add Firefox to tools/tests/test_engines.py').
- cmd_test fails a file that cannot load ('[FAIL] {file.name}: could not load') or that holds no test. No silent skip is possible.
- build counts tracked shipped files from `git ls-files --cached` (AUD-011). `build --release` fails on uncommitted or late shipped files and on stale crisis dates. The AGENTS.md Release row now names `build --release`, which agrees with the Instruction Changelog entry.
- run binds 127.0.0.1 (AUD-029). clean removes only output/ and tools/ caches. The test dependencies are pinned: `PIP_PACKAGES = ("playwright==1.63.0", "axe-playwright-python==0.1.8")` (AUD-032).
- bench now FLAGs over tolerance and fails only on a missed target (AUD-058). My four runs: launch 172 / 174.4 / 161.3 / 170.8 ms, all OK against 1000 ms. Size 193.7 KB FLAG (+3%), which is under 250 KB.
- The Slice 7 performance checkpoint entry is not yet due. Development_Process.md's Duties Matrix asks for it at 'Slice completes', and slice 7 closes only with this round and the 0.7.0 bump.
- check-manifests says 'inkscape is used and not declared' for Freelief. That is a false positive of the environment gate: make_icons.py renders the PNGs through `harness.browser()` (Chrome), and icons/icon.svg holds no inkscape markup (grep count 0). tools.toml stays empty under the AUD-012 ruling.
- Resource growth is bounded where I checked it. Old caches are deleted at activate. The runtime cache stores only same-origin, ok, basic responses, and `ignoreSearch` matching stops a query string from adding entries. The ripple sets are capped by `maxRipples`. The Visualizer shapes are capped by `maxShapes` (6).
