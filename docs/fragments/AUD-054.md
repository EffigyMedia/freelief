### AUD-054 - No procedure turns a volunteer accessibility check into a recorded standard

- Severity: Low
- Area: none - omission (create path of the Standard object)
- Evidence: Quoted in round UNT-010. data/standards.json: "_rule": "REQ-029: list a standard here only when an automated check of every page passes AND a manual check ... is recorded". Design section 2 has the owner "accepts volunteer checks". No document says who accepts a check, where the volunteer's issue is linked, what 'every page' means for the manual pass, or which test run proves the automated pass for that version. (quoted in round UNT-010)
- Impact: The first check that a volunteer sends meets no defined path. The owner must invent the rule while doing it, which is the moment an overclaim gets in.
- Direction: Write the acceptance procedure in the Standards trust-page technical reference: the required issue fields, the link to the issue, the version, and the automated run to cite. Have the standards entry carry the issue URL.
- Effort: S
- Found by: the omission lens of round [[UNT-010]].
