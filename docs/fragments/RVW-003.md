### RVW-003 - the security lens of round [[UNT-010]]

**Re-checks of the previous round:** none in this lens's brief.

**What was checked and found right:** No earlier finding to re-check: `grep -l 'kind *= *"audit"' docs/fragments/*` returned nothing, and the store holds no AUD- fragment. This is the line's first round.

Checked and right:
- Secrets and the never-commit list. `.gitignore` holds `.env`, `*.key`, `*.pem`, `feedback/`, `input/excluded/`, `.venv/`, `output/` and `.claude/settings.local.json`, which matches the AGENTS.md list "tokens, keys or passwords; `.venv/`; `output/`; `input/excluded/`; the content of feedback emails". `git ls-files` lists none of these. `git log --all -p` grepped for `ghp_|github_pat_|BEGIN ... PRIVATE KEY|<drive>:\Users` returned nothing. The only e-mail address in history is the git author identity, which AGENTS.md sets ("Commits are authored as the project owner"). `input/excluded/` is empty. The remote URL is `https://github.com/EffigyMedia/freelief.git`, with no credential in it.
- The no-network rule at run time. `sw.js`: `if (event.request.method !== "GET" || url.origin !== self.location.origin) return;`. `index.html` has a CSP meta of `default-src 'self'; ... script-src 'self'; connect-src 'self'; ... base-uri 'self'; form-action 'none'`, with no 'unsafe-inline' and no 'unsafe-eval'. `test_app.py` asserts `not foreign` over every request at launch. No shipped file calls eval, new Function or geolocation.
- Storage. `localStorage` appears only in `settings.js`, and both accesses are in try/catch. `tones` is checked with `typeof stored.tones === "boolean"` and `theme` with `config.theme.choices.includes(stored.theme)`.
- Region without location (REQ-005). `crisis.js` uses `new Intl.Locale(tag).maximize().region` from `navigator.languages`, inside try/catch.
- Feedback sends nothing itself (REQ-030). The message goes into `issue.searchParams.set("body", message.value)` and `encodeURIComponent(...)`, and only when the person activates a link. The textarea is filled through `.value`, not as markup. The e-mail choice stays hidden while `"feedbackEmail": ""`.
- `tel:`/`sms:` numbers go through `number.replace(/[^\d+]/g, "")`. Crisis-line text goes in through `textContent` (the `element()` helper).
- Hosting. `gh api repos/EffigyMedia/freelief/pages` returned `"https_enforced":true`. The public site serving `docs/` and `tools/` exposes nothing more than the public repository already does, and grep found no personal data or secret in those folders.
- The test harness binds `("127.0.0.1", 0)`, so the test server is not reachable from the network.
- No third-party code ships: no package manifest, no CDN reference, and `test_repo.py` and the CSP agree.

**Findings: 9.**
- Medium: Freelief shares its web origin with three other sites, and any of them can rewrite its offline cache and settings
- Medium: The router accepts inherited object names from the URL hash, so a link such as #constructor gives a blank app and a stuck router
- Medium: The Feedback page does not tell the person that a GitHub issue is public
- Medium: The design's control against a tampered crisis line ('every change goes through a reviewed commit') is not in place
- Low: `run` serves the whole repository, including .git, .venv and input/excluded, on all network interfaces
- Low: The stored-settings check accepts inherited object names, so a stored rhythm of 'constructor' breaks the breathing guide
- Low: No test guards the CSP, and the static external-load check misses common forms
- Low: setup installs the test dependencies unpinned and with no lock file
- Low: Pages build HTML from data with escaping that is not consistent

**Closing:** Not sound. Four Medium findings stop me saying "Sound as written". First, Freelief shares its origin with three other sites, and I proved that one of them can rewrite its offline cache. Second, a URL hash such as #constructor leaves the app blank, with a stuck router. Third, the Feedback page does not warn that a GitHub issue is public. Fourth, the design's reviewed-commit control on crisis lines does not exist (main is unprotected and has no ruleset). Five Low findings are also open.
