### AUD-144 - docs/README.md, the repository's public page, names v0.8.8 as the live preview while live serves v0.8.14, describes Trace a shape and the old Visualizer, and no step of a live move updates it

- Severity: Low
- Area: G. Documentation quality
- Evidence: Quoted in this round and in round UNT-124. docs/README.md: "One tap also reaches gentle activities (pop bubbles, trace a shape, the Unblock puzzle, a ripple pond and a mandala to color) and the Visualizer (slow shapes)." and "The preview serves **v0.8.8** (moved 2026-10-10 with the owner's yes). Each move of the preview is recorded in `docs/core/changelog.md` with the owner's yes, and this line names the version it serves." git log -1 origin/live: "4fac4ff Fix the interface review's low items (v0.8.14)". origin/live version.js: "0.8.14". Tags preview-0.8.10 and preview-0.8.14 exist. The changelog says 'The live preview moved to 0.8.14 on 2026-10-10' and 'moved to 0.8.10'. git log -- docs/README.md: the last change was 636107f 'Record the move of the live preview to v0.8.8'. Zen Garden is not named. Design section 10, Definition of done: "`docs/README.md` describes what a person sees (when the slice adds or changes a feature that users see)". The move rule (AGENTS.md Conventions; Instruction Changelog 'Tag every move of the live preview') names the owner's yes, the changelog and the tag, but not the README line. (quoted in round UNT-124)
- Impact: The README is the repository's public front page. A visitor or volunteer is told the preview is v0.8.8 and looks for a trace activity and a Visualizer that do not exist, and does not hear about Zen Garden or the Kaleidoscope. The README's own rule, that this line names the live version, has been false for two moves, so the line will keep drifting. That makes the page less trustworthy to the people who check accessibility.
- Direction: Rewrite the activity sentence with the owner's names: Pop Bubbles, Zen Garden, Ripple Pond, Color Mandalas, Unblock and Kaleidoscope. Set the preview line to v0.8.14. Add the README line to the steps of a live move (AGENTS.md and design section 7 row 10), or remove the version from the README and point to the changelog so that it cannot go stale. A test_repo check can compare the README's named version with the newest 'live preview moved to' entry in the changelog.
- Effort: S
