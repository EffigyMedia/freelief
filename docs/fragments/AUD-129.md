### AUD-129 - The test and bench server in harness.py serves the whole repository, including .git, .venv and input/excluded, to any Host name, the defect AUD-118 fixed only in `run`

- Severity: Low
- Area: E. Privacy & licensing
- Evidence: Quoted in round UNT-124. tools/tests/harness.py `serve()` builds `functools.partial(handler_class, directory=str(directory))` on `http.server.SimpleHTTPRequestHandler`, bound to `("127.0.0.1", 0)`, and `base_url()` calls `serve(ROOT)`. No Host check or path check exists in `_QuietHandler`. Every browser test and every `bench` run use this server (`from harness import ROOT, base_url, browser, wait_until` in tools/bench.py). In this round, a scratchpad script started `harness.base_url()` and sent requests with `Host: attacker.example:<port>`. The results were `/.git/HEAD attacker.example 200 b'ref: refs/heads/main\n'`, `/docs/fragments/THR-001.md attacker.example 200`, `/input/ attacker.example 200 b'<!DOCTYPE HTML>...'` (a directory listing) and `/.venv/pyvenv.cfg attacker.example 200 b'home = D:\\Code_Continuum\\Runtime\\uv\\pyth'`. Compare `run`, which since AUD-118 refuses both: `if self.headers.get("Host", "") not in hosts: self.send_error(403, ...)` and `if path not in shipped: self.send_error(404, ...)`. AUD-118's Impact named the exact reach, '.git (the history and config) and any file later placed in input/excluded/'. AGENTS.md says input/excluded/ holds what 'never is' committed. Confidence: the port is random and the server lives only for a run, so a DNS-rebinding page must first find the port. The server is up for minutes at a time: 'test' took 4m40s, and the health step ran 'bench' six times. No exploit was run, and input/excluded/ is empty today. (quoted in round UNT-124)
- Impact: The owner runs the suite at every unit and the bench at every release. During those runs, a hostile or compromised web page open in any browser on the development machine can rebind its own host name to 127.0.0.1, find the port, and read the repository through the browser. That reach includes .git, .venv (which shows local machine paths), output/ and anything later placed in input/excluded/. Today the reach is mostly the public repository. It grows silently when input/excluded/ is used. The finding AUD-118 closed stays open by another door.
- Direction: Give harness.serve() the same two refusals as run_handler. First, refuse with 403 any request whose Host is not `localhost:<bound port>` or `127.0.0.1:<bound port>`. Second, for serve(ROOT), refuse with 404 any path that is not a shipped file (freelief.shipped_files()). Copies that test_offline.py serves from a temporary folder already hold only the app. The simplest form is one handler factory that takes the port and the allowed set, shared by `run` and the harness. Extend test_run_serves_only_shipped_files_and_only_to_this_machine, or add a sibling test, so that it covers harness.serve with a foreign Host and with /.git/HEAD.
- Effort: S
