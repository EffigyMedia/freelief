### AUD-167 - The cross-engine offline test serves the whole repository with no Host check, unlike every other test server

- Severity: Low
- Area: H. Test coverage
- Evidence: Quoted in round UNT-139. tools/tests/test_engines.py `offline()`: `handler = functools.partial(http.server.SimpleHTTPRequestHandler, directory=str(ROOT))` on a ThreadingHTTPServer. tools/tests/harness.py says that its server does 'The same two refusals as `run` (AUD-118, AUD-129)': a foreign Host gets 403, and a path that does not ship gets 404. test_the_test_server_serves_only_shipped_files_and_only_to_this_machine checks only harness.serve. (quoted in round UNT-139)
- Impact: While the WebKit offline test runs (and the Firefox one, once it can start), .git, input/excluded and docs are served to any Host. The offline proof in the second and third engines also runs against files that GitHub Pages would never deploy, so it can pass where the deployed app would not.
- Direction: Build the server from harness.serve(ROOT), or from its handler class, and then stop it. If WebKit needs a server that can be shut down, add a `stop` handle to serve(). Keep the shipped-file list and the Host check.
- Effort: S
- Found by: the operations lens of round [[UNT-139]].
