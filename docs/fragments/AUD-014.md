### AUD-014 - Freelief's activate deletes every cache on the shared origin, not only its own

- Severity: Medium
- Area: C. Error handling
- Evidence: Quoted this round (UNT-010). sw.js activate: `caches.keys().then((keys) => Promise.all(keys.filter((key) => key !== CACHE).map((key) => caches.delete(key))))`. The technical reference app_shell_and_offline.md says "activate deletes every other Freelief cache". The origin effigymedia.github.io is shared with effigy-arcade and tiny-arcade, which both keep offline caches. (quoted in round UNT-010)
- Impact: Each Freelief update deletes the offline caches of Effigy Arcade and Tiny Arcade for anyone who uses both, so those apps lose offline use. The code does not do what its reference says.
- Direction: Filter by prefix: delete only keys that start with "freelief-" and are not CACHE. Add an assertion to the update test that a foreign cache name survives activation.
- Effort: S
- Found by: the operations lens of round [[UNT-010]].
- **RULED 2026-10-07T14:38:29-04:00** — Attempt 1, UNT-011 (v0.5.1): activate now deletes only keys that start with 'freelief-' and are not the current cache. test_offline.py runs a real update from a scratch copy (version changed on the server, registration.update()) and asserts that a foreign cache survives, the old Freelief cache is deleted and the new one exists. A later round confirms.
