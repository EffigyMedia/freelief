### RLG-006 — Launch time regressed to about 224 ms (baseline 110 ms, tolerance +25%): load the non-breathing screens lazily

Cause, by reading: app.js imports every screen statically, and each new screen (sounds, shapes, Calm) adds to what the browser parses before the breathing guide draws. Direction, already planned in docs/performance/log.md: import the non-breathing screens with dynamic import() on first visit, keeping breathing, the shell and urgent help in the first load.
