### AUD-098 - The network claims disagree: AGENTS.md says no network call after install, and REQ-015 and About say the update check is the only request, but the app also downloads missing files to repair its cache

- Severity: Low
- Area: A. Requirement compliance
- Evidence: Quoted in round UNT-082 at 82a1c6d. AGENTS.md What this is: "The app collects nothing and makes no network call after install." REQ-015 (amended, AUD-025): "After install, the only network request is the browser's check for a newer version of Freelief". about.privacy1 says "The only thing that reaches the internet is your browser's check for a newer version". The code also does this. app.js `healOfflineCache()` posts "heal" on each online launch, and sw.js then runs `cache.addAll(missing.map(...{ cache: "reload" }))` for any missing file. The sw.js fetch handler does `return fetch(event.request)` on a cache miss. Confidence note: these requests go only to GitHub Pages for Freelief's own files and carry nothing about the person, so the privacy intent holds. Only the word 'only' is not true, and AGENTS.md states the reverse of REQ-015. (quoted in round UNT-082)
- Impact: Under 'true claims only', a privacy claim on a trust page must be exact. The operative instruction file contradicts the owner's amended requirement, so a later session could remove the update check or the cache repair to 'comply' with AGENTS.md.
- Direction: Change AGENTS.md to the REQ-015 wording. Ask the owner whether REQ-015 and about.privacy1 should name the download of Freelief's own files (an update or a repair) as part of the same check, and record the ruling in REQ-015's history.
- Effort: S
