### AUD-026 - A device with no region set is shown the lines and emergency number of a guessed country, not the unknown-region path

- Severity: Medium
- Area: none - omission (unhandled state in F6)
- Evidence: Quoted in round UNT-010. crisis.js: "const region = new Intl.Locale(tag).maximize().region;". app_shell_and_offline.md: "A tag with no region gets its likely region, so `en` maps to `US` and `fr` to `FR`." REQ-005 says the lines are "chosen from the device language and region setting". Design F6 has the state "*uncurated region* — the 'call your local emergency number' line". No state exists for 'no region set'. test_help_shows_the_device_region_first tests only tags that have a region. There is no test for "en". (quoted in round UNT-010)
- Impact: A person whose device language is plain "en", in the UK, Ireland, Australia or anywhere else, is told "If you are in immediate danger, call 911." as fact, with US lines first. The design wrote the generic emergency line for exactly this uncertainty.
- Direction: Use maximize() only to read a region that the tag already has. When no tag carries an explicit region, use the unknown-region path (emergencyUnknown, the directory, all curated regions). Add the 'no region set' state to F6 and a test with locale "en".
- Effort: S
- Found by: the omission lens of round [[UNT-010]].
