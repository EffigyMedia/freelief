### REQ-017 — All user-facing text lives in one strings file per language, so a translation can be added without a code change. English is the only language in the first version.

**History.**
- 2026-10-07 (agreed in the design interview): the text above, with no exception.
- 2026-10-07 (UNT-012, implementer, for audit finding AUD-002): **one exception**, the static
  fallback in `index.html`. It holds five short lines (a breathing instruction, the emergency
  instruction, the directory link and the self-help line) that must show when JavaScript is off or
  the strings file cannot load. A translation adds a fallback per language. **The owner accepted
  this exception on 2026-10-07.**
- 2026-10-08 (UNT-077, AUD-039): a second documented exception. The crisis-line names, the country
  names and the hours in `data/crisis-lines.json` stay in that file, beside the number and the date
  each was checked against its source, because they are verified data, not interface text; a
  translation adds a translated copy of the data file. The feedback page's device text moved into
  the strings file (`feedback.mobileDevice`).
- 2026-10-09 (owner, AUD-101; UNT-101): **The owner accepted the second exception** (the crisis-line names, the country names and the hours stay in `data/crisis-lines.json`) on 2026-10-09, by the question tool.
