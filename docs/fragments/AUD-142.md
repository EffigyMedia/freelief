### AUD-142 - The Keep the screen on hint names 'the Visualizer', a name the person sees nowhere else

- Severity: Low
- Area: F. User experience
- Evidence: Quoted in this round. strings/en.json: "settings.awakeHint": "During breathing and the Visualizer, the screen stays on. ...". The menu and the screen title say "nav.calm": "Kaleidoscope" and "calm.title": "Kaleidoscope". The Decision Log entry on American spelling, amended 2026-10-10 (owner, RLG-057 and RLG-058), says: "the person now sees the name 'Kaleidoscope'; the route stays `#calm`." No other user-facing string says Visualizer. The omission lens found the same string in round UNT-124. (quoted in round UNT-124)
- Impact: A person who reads the hint cannot tell which screen keeps the screen on, because no screen is named Visualizer. The harm is small, but it is the kind of unclear text that a person with little attention meets in Settings.
- Direction: Change settings.awakeHint to name the Kaleidoscope. Add a test_repo check that no shipped string or issue template uses a name that the owner retired (Visualizer, Trace a shape, Trace, Sort colors, Sort, Standards and research).
- Effort: S
- Found by: the whole-design and omission lenses of round [[UNT-124]] - convergence.
