### AUD-118 - `run` serves the whole repository, including .git and input/excluded, to any Host name, so a web page open during a look check can read it by DNS rebinding

- Severity: Low
- Area: E. Privacy & licensing
- Evidence: Quoted in round at e695bfb. tools/freelief.py cmd_run: `subprocess.run([sys.executable, "-m", "http.server", str(PORT), "--bind", "127.0.0.1"], cwd=ROOT)`, which serves ROOT with SimpleHTTPRequestHandler. AUD-029 was closed by the bind alone. AGENTS.md: `input/excluded/` holds "Material that never leaves this machine". In this round, an in-process copy of that server (SimpleHTTPRequestHandler, directory = the repo root, bound to 127.0.0.1) was sent requests with the header `Host: attacker.example:8000`. It returned `/.git/HEAD 200 b'ref: refs/heads/main\n'`, `/input/ 200` (a directory listing) and `/docs/fragments/THR-001.md 200`, with no check of the Host header. The health check of this round also saw `.git/config`, `tools/` and `docs/fragments/` return 200 from the real `run`. Confidence: http.server does no Host validation, so a DNS-rebinding page can read these files. No exploit was run, and input/excluded/ is empty today. Related to AUD-029, whose bind fix this does not undo. (quoted in round UNT-104)
- Impact: While the owner runs `run` for a look check, a hostile or compromised web page that is open in any browser on the machine can rebind its own host name to 127.0.0.1 and read the repository through the browser. That includes .git (the history and config) and any file later placed in input/excluded/, which the rules say never leaves the machine. Today the reach is the public repository plus an empty folder. The reach grows silently when input/excluded/ is used.
- Direction: Serve only what ships. Copy or filter the shipped files (freelief.shipped_files(), which build already computes) into a temporary directory, or use a handler that refuses any path not in that list. Also refuse a request whose Host header is not localhost:8000 or 127.0.0.1:8000. Add a test that `run`'s handler returns 404 for /.git/HEAD and /input/, and 400 or 403 for a foreign Host.
- Effort: S
- Found by: the security lens of round [[UNT-104]].
