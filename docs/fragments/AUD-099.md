### AUD-099 - The static fallback and config.json hold copies of the directory URL and the default rhythm, and nothing ties them to their source

- Severity: Low
- Area: B. Duplicate implementations
- Evidence: Quoted in round UNT-082 at 82a1c6d. `git grep findahelpline` finds the directory URL in data/crisis-lines.json ("url"), in config.json ("directoryUrl") and in index.html's fallback. Only the data file carries a checked date, and `build --release` checks only it ("crisis data checked more than ... days ago"). tests/test_startup.py pins the other two copies to the literal string and does not compare them with the data file. The fallback says "Breathe in while you count to four. Breathe out while you count to six." `git log -S` shows this text unchanged since 0e43acb. The default rhythm was box (4-4-4-4) from UNT-031 to UNT-050, so in that period the fallback and the app disagreed, and no test failed. (quoted in round UNT-082)
- Impact: The directory link is the fallback route for a person in danger. If the data file's URL is corrected after a check, the two other copies can keep the old one with every test green. The rhythm text can drift again at the next default change.
- Direction: Add repo tests that config.crisis.directoryUrl and the fallback link equal data/crisis-lines.json's directory URL, and that the fallback's counts match config.breathing.defaultRhythm. Alternatively, record in the design that these copies must change together, and have `build --release` check them.
- Effort: S
