### AUD-027 - The offline test and the network test cover only breathing and the help dialog, not every screen

- Severity: Medium
- Area: none - omission (coverage the design promises)
- Evidence: Quoted in round UNT-010. Design section 2: "After install, an automated test with the network disabled shows every screen working, and a network log shows no request to any origin". Section 9: "*Offline:* after one visit, with the network off, every screen works". test_the_app_works_offline_after_one_visit asserts only "page.locator(\".guide\").is_visible()" and the help lines. test_no_request_leaves_the_origin opens only the help dialog. The Standards screen fetches data/standards.json and data/research.json after launch, and no offline test opens it. (quoted in round UNT-010)
- Impact: A screen that fails offline (for example a data file missing from the cache, or a fetch that is not cached) passes the suite. Offline use is on the never-break list.
- Direction: Extend the offline test so that it visits every route in ROUTES with the network off, and asserts that main.dataset.shown matches and the console is clean. Extend the network test to every route.
- Effort: S
- Found by: the omission lens of round [[UNT-010]].
