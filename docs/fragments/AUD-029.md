### AUD-029 - `run` serves the whole repository, including .git, .venv and input/excluded, on all network interfaces

- Severity: Low
- Area: E. Privacy & licensing
- Evidence: tools/freelief.py cmd_run: `subprocess.run([sys.executable, "-m", "http.server", str(PORT)], cwd=ROOT)`, with no `--bind`. `http.server` help says `--bind ... (default: all interfaces)`. While `run` was up, curl returned `.git/config -> 200`, `.git/HEAD -> 200`, `.venv/pyvenv.cfg -> 200` and `.claude/settings.json -> 200`. AGENTS.md: "`input/excluded/` never is [committed]" and is the material that "never leaves this machine". The test harness, in contrast, binds `("127.0.0.1", 0)`. `input/excluded/` is empty today and the remote URL holds no credential, so no exposure is known now. (quoted in round UNT-010)
- Impact: Any device on the same network (a cafe, a shared house) can read the repository history and any file later put in `input/excluded/` while the owner runs the app for a look check.
- Direction: Pass `--bind 127.0.0.1`. If a phone check over the LAN is wanted, make that a separate, named option and print a warning when it is used.
- Effort: S
- Found by: the security lens of round [[UNT-010]].
