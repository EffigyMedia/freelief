### AUD-066 - The Visualizer activity reads and writes Settings itself, which breaks the boundary that activities stay free of storage

- Severity: Medium
- Area: B. Architecture quality
- Evidence: Quoted in round UNT-051. activities/calm.js: `import { getSetting, setSetting } from "../settings.js";`, then `getSetting("calmMode")` and `setSetting("calmMode", input.value);`. Design Stage 8, activities row: "Must not: Keep a score, a timer or a failure state; read storage." AGENTS.md: "Exercises ... and activities ... must not touch storage". The Decision Log (slice 2): "the exercises stay free of storage: the Settings screen is not an exercise, and it writes only through `settings.js`". The shell passes settings into ctx for exactly this reason (`rhythm: getSetting("rhythm"), soundsOn: getSetting("sounds")`). No Decision Log entry records an exception for calm.js. (quoted in round UNT-051)
- Impact: One activity now persists a choice to localStorage through a path that the contract forbids, and it bypasses the ctx contract. The next activity can copy the pattern. Module tests that stub ctx no longer isolate the activity from stored state. The breach is contained, because settings.js still guards the storage access.
- Direction: Either pass the Visualizer's mode and a setter through ctx (for example ctx.calmMode and ctx.saveCalmMode, with the setter owned by the shell), or record an owner-decided Decision Log entry that lets an activity persist its own choice through settings.js, and update Stage 8 and AGENTS.md to match. Add a repo test that no file in activities/ or exercises/ imports settings.js, unless an exception is listed.
- Effort: S
- Found by: the whole-design lens of round [[UNT-051]].
- **RULED 2026-10-08T02:09:13-04:00** — Fixed in UNT-058 as v0.5.43 by the first direction: calm.js no longer imports settings.js; the shell passes ctx.calmMode and ctx.saveCalmMode, and the Visualizer keeps the current mode in its own state. New repo test: no file in exercises/ or activities/ names settings.js, localStorage or sessionStorage. The remembered-mode test still passes. 124 tests.
