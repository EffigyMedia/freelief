**What was checked and found right:** These checks are right as written. (1) The saved rhythm is validated against own keys: `if (Object.hasOwn(config.breathing.rhythms, stored.rhythm)) values.rhythm = stored.rhythm;`. A preset that is later removed therefore falls back to the default. (2) The long out-breath change of v0.5.36 is consistent in config, tests and records: config.json `\"defaultRhythm\": \"calm\"` and `\"rhythmOrder\": [\"calm\", \"slow\", \"box\"]`; test_slice2 `assert default == \"calm\", \"owner, 2026-10-08: the long breath out the research favors\"`; REQ-023 has the dated history line \"2026-10-08 (owner, UNT-050): back to 4-in 6-out as the default\"; the Decision Log entry is annotated, not rewritten. The static fallback in index.html says \"Breathe in while you count to four. Breathe out while you count to six.\", which agrees with the new default. Box breathing is still offered and has its own test (test_box_rhythm_holds_after_the_in_breath). (3) The router accepts only its own names: `return Object.hasOwn(ROUTES, name) ? name : DEFAULT_ROUTE;`. (4) A screen that cannot load falls back to the default route: `if (name !== DEFAULT_ROUTE) return show(DEFAULT_ROUTE, { moveFocus });`. (5) The worker deletes only its own caches: `.filter((key) => key.startsWith(PREFIX) && key !== CACHE)`. It answers only from its own version's cache: `caches.open(CACHE).then((cache) => cache.match(...))`. (6) The settings round trip and blocked storage are tested, and every storage access in settings.js is in try/catch. (7) A saved help region that is no longer curated falls back safely: \"A saved region that is no longer curated shows as Automatic\". (8) Every activity on the menu maps to a research section, by test. (9) The fallback.js 2 s constant is documented as a deliberate exception in the Decision Log.
