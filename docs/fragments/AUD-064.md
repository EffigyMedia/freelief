### AUD-064 - The owner's decision to open on the menu was never carried into AGENTS.md, Design F1, Stages 2, 6 and 8, or the README, which still say that the breathing guide starts at launch

- Severity: Medium
- Area: G. Documentation quality
- Evidence: Quoted in round UNT-051. The code and the records agree: REQ-018 "When Freelief opens, it shows the menu", and app.js `const DEFAULT_ROUTE = "menu";`. The live authorities still say the reverse. AGENTS.md What this is: "The breathing guide starts at launch with no question, menu or notice." AGENTS.md Architecture: "Routing is by URL hash (`#breathe` is the default)". The F1 heading was changed to "Launch to the menu", but its body still reads "Steps: the shell paints; the breath guide starts with the saved rhythm (or the default) and one calm line." Stage 6: "Help first: the breath guide is the first and default screen." Stage 8 Routing: "no hash means `#breathe` ... an unknown hash falls back to breathing." Stage 2 success criterion: "the breathing guide is visible within 1 second ... with zero taps (REQ-018, REQ-026)", which PRD.md regenerates. docs/README.md: "Freelief opens straight into a breathing guide." A comment in app.js show() says "falls back to breathing, which is always loaded", but the code falls back to DEFAULT_ROUTE (the menu), and breathe.js is loaded on demand. The Instruction Changelog has no entry for the change. The omission lens found the same stale F1 steps, Stage 2 zero-taps criterion and Stage 8 routing line. (quoted in round UNT-051)
- Impact: AGENTS.md is the first file that every session reads, and it states the opposite of an owner decision about the primary flow, in bold, as a crisis rule. A later session that follows it could 'fix' the launch back to breathing and reverse the owner's choice. The public README misstates what a person sees first. The generated PRD carries a success criterion that the app cannot meet.
- Direction: Rewrite the AGENTS.md sentences, the F1 body, Stage 6, the Stage 8 routing paragraph, the Stage 2 criterion and the README to say that Freelief opens on the menu with Breathe first, and delete the old wording in the same edit. Correct the app.js comment. Add an Instruction Changelog entry, because AGENTS.md changes. Regenerate the SRS and the PRD.
