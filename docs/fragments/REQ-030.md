### REQ-030 — A feedback page opens a pre-filled GitHub issue (accessibility check or problem report). Once the owner chooses a public project email address, the page also offers, as a second choice, a pre-filled email to that address; until then GitHub is the only route. The pre-filled text holds only the app version, browser and device type, and the person sees and can edit all of it before they send. The app itself sends nothing.

**History.**
- 2026-10-07 (agreed in the design interview): "A feedback page opens a pre-filled GitHub issue
  (accessibility check or problem report) and, as a second choice, a pre-filled email to the public
  project address."
- 2026-10-08 (owner, AUD-020): changed. The email route is optional. GitHub is the route; the
  pre-filled email is offered once the owner chooses an address. The design had let a release hide
  the email button, which contradicted a "must" that required it.
