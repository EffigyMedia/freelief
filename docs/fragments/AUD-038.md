### AUD-038 - The breathing guide and the bubble field keep every timer id for the whole session

- Severity: Low
- Area: D. Memory
- Evidence: Quoted this round (UNT-010). exercises/breathe.js runPhase pushes one timer per second plus one per phase: `run.timers.push(setTimeout(...))`; the array is emptied only by `clearTimers()` on pause and by stop(). activities/bubbles.js pushes two per pop: `current.timers.push(setTimeout(remove, settings.popMs)); current.timers.push(setTimeout(addBubble, settings.respawnMs));` and empties only on stop(). With the default 4-in, 6-out rhythm that is about 12 ids per 10 seconds, about 4,300 per hour. (quoted in round UNT-010)
- Impact: Small, but unbounded: a person who leaves the guide running for hours (the installed app is meant to stay open) grows an array of dead ids. No user-visible effect at normal session lengths.
- Direction: Remove a timer id from the array when it fires, or clear the array at the start of each phase since the previous phase's timers have all fired.
- Effort: S
- Found by: the operations lens of round [[UNT-010]].
