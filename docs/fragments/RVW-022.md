**What was checked and found right:** Checked and found right (all quoted in round UNT-139):
- Cache ownership on the shared origin. sw.js `activate` deletes only keys where `key.startsWith(PREFIX) && key !== CACHE`, and it keeps the highest other version with `others.slice(0, -1)`. Another app's cache survives, and test_offline checks this.
- Precache freshness. `new Request(file, { cache: "reload" })` is used in precache, refresh and heal, and registration uses `updateViaCache: "none"` (AUD-013).
- One version per answer. The fetch handler opens a single cache (`caches.has(own).then((kept) => caches.open(kept ? own : CACHE))`) and never uses `caches.match()` across caches. A Cache Storage fault falls back to the network: `.catch(() => fetch(event.request))`.
- Heal and fetch-through never store a newer deploy. Both go through `thisVersionIsDeployed()` (AUD-120), and test_a_newer_deploy_is_never_stored_in_the_running_versions_cache covers this.
- Update now is safe on a captive portal and when one file fails. `registration.update()` failure gives 'settings.updateFailed', and the refresh copies only after `fresh.addAll` succeeds. Both have tests.
- Start-up failure. `boot().catch` puts back the static fallback, and fallback.js shows it after `REVEAL_AFTER_MS = 2000` if `dataset.ready !== "true"`, with no dependency on config.json. test_startup covers config, strings, app.js, menu.js, JavaScript off, and a menu that throws.
- A failed crisis file is non-fatal. loadCrisisLines catches the error, logs 'Freelief could not load the crisis lines', and the dialog keeps `config.crisis.directoryUrl`. The data shape is pinned by test_every_crisis_number_is_pinned.
- Every storage access in settings.js is inside try/catch. Unknown values and newer-version values are written back unchanged (`foreign`), so a rollback keeps choices.
- wakelock.js releases a lock that is granted late: 'if (!wanted || idle || sentinel) { granted.release()'.
- Long-session growth is bounded. Garden lines are trimmed at `maxLines` 2500 and items at `maxItems` 6. Ripple removes old ring sets. calm.js removes old layers after the fade, and its `later()` drops fired timer ids. The audio pads delete ended oscillators (`oscillator.onended = () => live.delete(oscillator)`), and `fading` entries expire.
- The test runner fails loudly. '[FAIL] {file}: could not load' and 'holds no test_ function' each count as failed. NotRun is never counted as a pass.
- `run` and the harness server refuse non-shipped paths and foreign Host headers. The health probe got 404 'Not a shipped file' for docs/Design_Document.md.
- `build --release` checks the size, uncommitted shipped files, a version bump after the last shipped change (`version_not_raised` against the preview-/v tags), and crisis dates, which must not be stale or in the future.
- The rollback story exists. The Incident row says 'before 1.0 the previous `preview-X.Y.Z` tag'. `preview-0.8.22` resolves to the live commit 4ef8821, and origin/live equals main.
- Site retirement is designed (Design section 9, 'Moving or retiring the site (AUD-111)'). The person-side removal is stated in about.privacy2: 'Clearing your browser data removes them.'
- Test packages are pinned (`PIP_PACKAGES`), and doctor verifies every pin.
