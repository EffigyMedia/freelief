### RLG-019 — Urgent help: the app under the open dialog must not take touches (owner report)
- **RULED 2026-10-07T23:57:49-04:00** — Built in UNT-041 as v0.5.27. Reproduced with CDP touch events at 390 x 640: a tap on the backdrop did nothing, but a swipe on it scrolled the page under the dialog from 0 to 646 px. Fix: the shell adds help-is-open to the html element while the dialog is open (overflow hidden on html and body) and removes it on close; .help has overscroll-behavior contain. Test test_the_page_under_urgent_help_takes_no_touch: a backdrop swipe and four swipes past the end of the list leave scrollY at 0, the list itself scrolls, a backdrop tap does not navigate or close, and the page scrolls again after close. Proven: with the fix stashed, the test fails at the first check. 103 tests.
