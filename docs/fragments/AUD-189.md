### AUD-189 - The shell's technical reference describes only the three-row header and has no word on the one-row landscape layout

- Severity: Low
- Area: G. Documentation quality (technical references synced to code)
- Evidence: Quoted in round UNT-155. docs/technical_references/app_shell_and_offline.md, The header and the footer: 'The header is three centered rows (RLG-049): the name ...; then five round buttons ...; then "Need urgent help?" on its own line, as text.' styles.css since v0.8.29 (AUD-162): '@media (orientation: landscape) and (max-height: 500px) { .top { flex-direction: row; ...' with the comment 'The header is one row, and each play area fits the height left under it'. The Decision Log entry 'Landscape works on a phone' describes it. A grep for 'landscape' over docs/technical_references/ finds nothing. (quoted in round UNT-155)
- Impact: The owning document of the shell does not describe the header on a phone held sideways, which is where 'Need urgent help?' moves from its own row to the end of a single row. A session that changes the header from the reference can break the landscape layout, and only an owner check on a phone would see it.
- Direction: Add a short paragraph to the header section of app_shell_and_offline.md. It names the media query, says that the header is one row and that each play area fits under it (the selectors in the block), and points to AUD-162 and the Decision Log entry.
