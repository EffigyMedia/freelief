### AUD-143 - The volunteer's GitHub accessibility template still lists removed screens and omits the current ones, and no test or removal rule ties it to the in-app checklist

- Severity: Medium
- Area: F. User experience
- Evidence: Quoted in round UNT-124. .github/ISSUE_TEMPLATE/accessibility-check.md, 'What I checked:': '- [ ] Trace a shape', '- [ ] Sort colors', '- [ ] Visualizer, with its full screen and black screen', '- [ ] About, Standards and research, Feedback'. It has no Zen Garden, no Unblock and no Kaleidoscope. The in-app strings/en.json feedback.template.accessibility lists '[ ] Zen Garden', '[ ] Unblock', '[ ] Kaleidoscope, with its full screen and black screen' (fixed in UNT-123: 'the Feedback checklist uses the current screen names'), so the twin was fixed in one place only. Feedback's 'Open on GitHub' sets `template` to project.issueTemplates[kind], and docs/README.md links '[accessibility check](../../../issues/new?template=accessibility-check.md)'. test_slice4.py checks only that each template 'is_file()' and holds 'issues are public' and 'Need urgent help?'. The Instruction Changelog has a rule for adding a screen ('A new screen goes into four lists') and a rule for its owner checks on removal ('Retire an owner check when its screen is removed'), but no rule for the other text that names a screen. AUD-126's fix (UNT-118) shows the same pattern: the sweep of a removed screen was done once and missed clauses in the design, the SRS, the technical references and the config (recorded as separate findings in this round). (quoted in round UNT-124)
- Impact: The manual screen-reader and keyboard check is a 1.0 release condition (design section 10; RLG-033), and Unblock's manual check is the one specifically owed. A volunteer who opens the template from GitHub or the README is asked about three screens that do not exist and is not asked about Unblock, Zen Garden or the Kaleidoscope.
- Direction: Replace the template's checklist with the in-app one and drop 'Standards and research'. Add a test that the template's checklist lines equal the checklist in feedback.template.accessibility. Add to the removal rule in AGENTS.md: a removed or renamed screen is swept from the strings and the issue templates in the same unit. Write a removal checklist beside the four-list rule: design module table, tunables, F-flows, risk table, technical references, config groups, strings, templates, README.
- Effort: S
- Found by: the omission lens of round [[UNT-124]].
